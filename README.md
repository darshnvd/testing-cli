# testing-cli

A command-line interface tool for testing purposes.

## Overview

`testing-cli` is a lightweight project used to experiment with CLI tooling, GitHub workflows, and automation. It serves as a sandbox for trying out new development practices and integrations.

## Getting Started

### Prerequisites

- [Git](https://git-scm.com/) installed on your machine
- A GitHub account (for contributing)

### Installation

Clone the repository and start building your CLI tool:

```bash
git clone https://github.com/darshnvd/testing-cli.git
cd testing-cli
```
