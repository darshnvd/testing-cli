# testing-cli

A command-line interface tool for testing purposes.

## Getting Started

Clone the repository and start building your CLI tool:

```bash
git clone https://github.com/darshnvd/testing-cli.git
cd testing-cli
```

## Usage

```bash
# Run the CLI tool
./testing-cli --help
```

## Features

- Lightweight and fast
- Easy to extend
- Cross-platform support
